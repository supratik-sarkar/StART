# DESIGN FREEZE — StART Greenfield Webapp

The visual/product implementation in `webapp/` is the greenfield baseline. Wiring work must **not** use the legacy frontend as a reference.

Frozen design principles:
- Porcelain/light-first engineering workspace
- graphite typography, hairline borders, restrained lavender/sage/amber accents
- no dark/navy shell
- no default analytics
- ML/DL-first workflow hierarchy
- empty intent-first composer
- living execution path with animated current-state travel
- parent/child lineage first-class
- tool/test calls rendered as structured runtime objects
- evidence explorer with direct provenance
- findings only after evidence exists
- contextual Agent ↔ Human conversation
- explicit proposed actions before child execution
- real progress only; phase-only when percent is unknown
- substantial governance/sign-off state with reverse trace to lineage

Antigravity may make only compatibility-level changes required to bind real canonical backend contracts. Any broader visual/product change must be separately authorized by the user.
